# Раззработка тестов, которые проверяют работоспособность методов для контроллера pet (pet Everything about your Pets).

##Исходные данные
1. сервис для работы с животными% https://petstore.swagger.io
2. swagger спкцификация для сервиса: https://petstore.swagger.io/v2/swagger.json

## Минимальные проверки:
1. позитивный тест: ответ 200
2. позитивный тест + проверки что тело не пустое
3. негативный тест (например при некорректном входном запросе к сервису)
4. можно расширить и добавить собственные проверки на основании данных, которыми оперирует сервис (напрмер, что имя животного не пустое)

## Основной язык реализации Java
## Основной стек проекта автоматизации (автотестов)
1. RestAssured (клиент и работа с JSON)
2. JUnit (ранер автотестов)
3. Allure (отчеты по выполненрию автотестов)
